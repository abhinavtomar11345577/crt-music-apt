FSpotify 1.2.0

A terminal music and internet radio player. It is a Python program driving mpv, so it runs anywhere those run.

Searching asks the YouTube Music catalogue, so an artist's name brings back that artist's songs, with artist and length beside each one, rather than every video ever made about them.

Linux and macOS

curl -fsSL https://abhinavtomar11345577.github.io/crt-music-apt/setup.sh | sh

On Debian, Ubuntu, Mint, Pop!_OS and Raspberry Pi OS that adds this signed APT repository and installs the crt-music package, so the app updates with the system. On Arch, Fedora, openSUSE, Alpine, Void, Gentoo, macOS and the rest it installs the player under ~/.local using whatever package manager is there. Add --dry-run to see what it would do, or --uninstall to remove it again:

curl -fsSL https://abhinavtomar11345577.github.io/crt-music-apt/setup.sh | sh -s -- --dry-run

Windows

In PowerShell (no administrator rights needed):

irm https://abhinavtomar11345577.github.io/crt-music-apt/install.ps1 | iex

That installs Python's curses support, mpv, yt-dlp and the player into %LOCALAPPDATA%\crt-music, and adds a Start menu entry. To inspect or undo it:

& ([scriptblock]::Create((irm https://abhinavtomar11345577.github.io/crt-music-apt/install.ps1))) -DryRun
& ([scriptblock]::Create((irm https://abhinavtomar11345577.github.io/crt-music-apt/install.ps1))) -Uninstall

By hand

The player is a single file. With Python 3.9+, mpv and yt-dlp installed:

curl -fsSL https://abhinavtomar11345577.github.io/crt-music-apt/crt-music -o crt-music
chmod +x crt-music
./crt-music

APT repository by hand

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://abhinavtomar11345577.github.io/crt-music-apt/apt-key.asc | sudo gpg --dearmor --yes -o /usr/share/keyrings/crt-music.gpg
echo "deb [signed-by=/usr/share/keyrings/crt-music.gpg] https://abhinavtomar11345577.github.io/crt-music-apt stable main" | sudo tee /etc/apt/sources.list.d/crt-music.list
sudo apt update
sudo apt install crt-music

Remove it with sudo apt remove crt-music.

If YouTube will not play

YouTube only serves streams to a current yt-dlp, and the one packaged by most distributions is far too old. The installers handle this; if it happens later, run:

crt-music --update-ytdlp

crt-music --check reports what is installed and what is stale.
